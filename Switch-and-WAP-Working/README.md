# Switch and Wireless Access Point Working – Cisco Packet Tracer

## Overview

This project demonstrates the basic working of a network switch and a Wireless Access Point (WAP) using Cisco Packet Tracer.

The lab focuses on understanding how wired and wireless devices communicate through a network, how a switch operates at Layer 2, and how a Wireless Access Point provides network connectivity to wireless devices.

This hands-on lab was completed as part of my self-learning journey in computer networking and cybersecurity.

---

## Objectives

The main objectives of this lab are:

- Understand the basic working of a Layer 2 Ethernet switch.
- Understand the role of a Wireless Access Point in a network.
- Connect wireless devices to the network through a WAP.
- Understand communication between wired and wireless devices.
- Verify network connectivity using ICMP.
- Observe packet transmission using Cisco Packet Tracer Simulation Mode.
- Analyze packet information using the OSI model and PDU details.
